What's different this time

I dropped the AI-illustration chase and went heraldic. Every patch carries:

1. A circular field with double-ring border (rope outer · dashed embroidery middle · solid inner), the way real military mission patches are constructed.
2. A Roman numeral at the top (I → VIII) instead of a number — gives the system "order"/"rank" flavor.
3. Laurel decorations around the top arc (sparser for ranks I-VII, fuller + crowned for rank VIII).
4. A creature crest centered with embossed gradient + cast shadow + dashed stitch lines for the embroidered feel.
5. A bottom banner ribbon with the tier name in CINZEL (the serif used on real institutional crests + most coat-of-arms work).
6. A grand-order name above each patch (Order of Plankton · Order of the Reef · Order of Eight · Order of the Tides · Order of the Pod · Order of the Hunt · Order of the Deep · Sovereign of the Abyss).
7. Apex patch (Hump Back) gets a gold double-border, a crown above the numeral, denser laurels, a gold ribbon — the same way the highest-grade military insignia separates itself from the rest.

This is fundamentally different from every previous attempt: no "creature in a tier-color circle" — these are achievement decorations. If this direction lands, say "go heraldic". If not, tell me what's wrong and I'll cut another direction.
