Feature inventory — pick what to ship

Identity (must-have)

  • Pseudo — display name. Self-set. Uniqueness check needed. Fallback to EaAL…pLBt.
  • Avatar — three flavours: (a) generated identicon from wallet (always works, zero storage), (b) NFT PFP — pick from NFTs the wallet currently holds (must own; auto-falls back if sold), (c) uploaded image to Vercel Blob.
  • Wallet address — always shown, copyable, Solscan-linked.

Stats — derived from on-chain (no storage needed)

  • Lifetime tickets bought, SOL spent, pools entered, pools won, total SOL won, biggest single win, net PnL, win rate vs. expected rate.
  • Creator stats (if they've launched pools): pools created, total tickets sold, fees collected, average fill rate.
  • Streak counter — consecutive plays or consecutive wins/losses.
  • Leaderboard rank — already have a leaderboard, just link to the user's position.
  • Activity heatmap — buys per day, last 14 weeks (cheap to compute, very legible).

Optional — gamification

  • Badges / achievements — "first win", "10 pools entered", "200+ tickets", "fastest settle", "lost 5 in a row" (dark humour OK).
  • Title — auto-assigned from badges, e.g. "Whale", "Lucky", "Degen".
  • Follow other wallets + activity feed of who you follow.
  • Referral code — invite codes that credit the inviter when the invitee buys.

Optional — social

  • Bio (140 chars).
  • Linked social handles — 𝕏, GitHub, Telegram. Verification: sign a Tombola-issued nonce with wallet, post the nonce on Twitter, we scrape it.
  • Country / timezone display (self-set, optional).
  • Banner image (subtle; default to a gradient).
  • Pinned pool — creator's featured pool or buyer's biggest win.

Architecture decisions to settle

  • Where do pseudo + bio + linked-handles live? On-chain (a UserProfile PDA per wallet, ~200 bytes, costs ~0.002 SOL rent per user) — censorship-resistant, no backend, decentralised vibes. Off-chain (Upstash KV via Vercel) — zero gas, faster updates, but a Tombola server has to be up.
    Recommendation: off-chain to start (fast iteration), migrate to PDA later if it matters.
  • How do we prevent pseudo squatting? First-come first-served + minimum-tickets-bought-to-claim threshold? Or premium reservation (claim costs 0.01 SOL)?
  • NFT PFP gating — keep it simple by accepting any NFT the wallet owns, OR restrict to a Tombola-issued PFP collection so it stays on-brand.
  • Account opt-out — anyone can browse /u/EaAL…pLBt by raw wallet, but profile owner can hide their stats. (Recommendation: opt-out, not opt-in. Reputation is most useful when on by default.)

What I'd ship in v1 (smallest interesting slice)

  • Option A (compact card) embedded in the existing creator/buyer dashboards + on the pool detail pages where the buyer's address appears.
  • Identicon avatar by default + optional NFT PFP picker.
  • Self-set pseudo stored in Upstash KV. Uniqueness check via the same KV.
  • Five stats: tickets bought, pools entered, wins, win rate, net PnL — all on-chain derived.
  • 3 badges max in v1 (first win / 10 pools / whale). More can come later.
  • NO bio / NO linked-socials / NO heatmap / NO follow graph in v1 — defer.
