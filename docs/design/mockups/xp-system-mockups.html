XP / Level system — visual proposal

6 tiers · 100 levels · plankton to mythic ocean lord · cosmetic-only v1

1 · Six tier examples

One badge per tier so the visual language is legible at a glance. Each badge is rendered as inline SVG — same component, parameterized by level, no asset pipeline. Lower tiers have flat single-color silhouettes; mid tiers introduce gradients + glow; mythic tier (L86+) gets the animated holographic rim.

3 · IdentityPill — level ring + chip

Adds a small tier-colored ring around the avatar with a numeric level chip in the bottom-right corner. The badge ring tints to match the user's current tier (lavender = Tier 2, mint = Tier 3, etc.). Compact enough to fit in the existing pill width.

4 · Level-up moments

Two intensities. Most level-ups (within a tier) get a small toast at the corner — non-blocking, ~4s autohide. Tier-crossings (e.g. L25 → L26 = entering Open Ocean) get a full modal with animation + flavor text. Mythic-tier entries (L86+) get the same modal with particle effects added.

5 · Open product decisions

Each row is a decision the founder needs to make before phase-1 code. The "recommendation" column is my best guess given the brand + audit work to date. Approve or change-request inline; I'll update the spec doc and start phase 1 when all green.

XP lifetime vs seasonal? Lifetime. Matches the shrimp-to-whale evolution narrative. Seasonal ranks can land later as a parallel competition.
Other users see your level? Yes by default · respects `profile.isPublic`. Status doesn't work in private. Private profiles already hide stats; level joins that set.
Cosmetic or unlock perks? Cosmetic only for v1. Functional perks would touch protocol economics — out of scope. Future options: pool theming at L50+, profile flair at L75+. Never fee discounts.
XP source mix? 40% activity · 30% loyalty · 30% value. Tunable as server weights, no schema change. Avoids spend-pure (whales auto-win) and activity-pure (farming).
Backfill existing users? Yes. See §6 of PROPOSAL.md. Without it, day-1 users see "Lv. 1 Plankton" and feel demoted. Backfill targets active users to L5–30.
Empty private pools earn XP? Yes, small (100 XP). Effort acknowledged, but no big reward without participants.
Consolation XP for losing? None extra. Already covered by the per-ticket grant — playing IS the participation reward.
Badges as NFTs at L75+? Defer. Cool optionality. Make badge metadata addressable now (`/api/badge/[level]/metadata.json`) so the door stays open without a hard commit.
Audio on mythic level-up? Default off · per-user toggle in settings.
Admin flag threshold for farming? > 10,000 XP/day surfaces in risk feed. No auto-block — admin reviews + decides.

Approve / change-request each row in §5, then I'll write the locked SPEC and start phase 1 (math + schema + tests).
