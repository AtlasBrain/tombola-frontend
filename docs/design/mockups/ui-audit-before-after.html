02

Color palette fragmentation

CSS variables exist in globals.css but 18 component files redeclare the same hex values inline. Casing drift (#E89999 vs #e89999) and naming drift (PINK ≠ --pink).

Before · scattered inline hex
// src/components/CreatorDashboard.tsx
const MINT = "#88cfc4";

// src/components/ProfileCard.tsx
const MINT = "#88cfc4";

// src/components/InviteFriendsTab.tsx
const MINT = "#88cfc4";
const SAND = "#e8d89e";

// src/components/BuyerDashboard.tsx
const ACCENT_PINK = "#E89999";  // uppercase E

// src/components/PoolInviteBanner.tsx
const CORAL = "#e89999";        // lowercase e

// globals.css
--pink: #e8a5c0;                /* totally different */

Same color, 3 different names, 2 different casings. Visually identical, but maintenance pain.

After · single source of truth
/* globals.css — canonical names */
--mint:     #88cfc4;
--lavender: #c9b5dc;
--coral:    #e89999;
--sand:     #e8d89e;
--rose:     #e8a5c0;

// anywhere in the app
style={{ color: "var(--mint)" }}
// or via Tailwind utilities
className="text-mint border-mint"

Drop all const MINT = "#88cfc4" declarations. Codemod = ~30 min.

08

Accessibility — text contrast fails at 9px

WCAG AA requires 4.5:1 contrast for body text under 18px. text-neutral-600 on bg-neutral-950 at 9px fails.

Before · multiple combos fail
neutral-500 · 9px label 3.5 : 1 FAIL
neutral-600 · 9px label 2.7 : 1 FAIL
neutral-700 · 10px label 1.9 : 1 FAIL

Several stat sub-texts in the wild use these. Borderline unreadable on small screens.

After · lift the minimum to neutral-400
neutral-400 · 10px label 6.1 : 1 PASS
neutral-400 · 12px body 6.1 : 1 PASS
mint · 10px label 8.4 : 1 PASS

Drop text-neutral-600 for any label under 12px. Reserve text-neutral-500 for ≥12px only.

09

Legacy lime alias is misleading

globals.css has .bg-lime { background: var(--lavender); }. The class says lime; the color is lavender. Holdover from an early mockup that never got renamed.

Before · misleading alias
/* globals.css */
.bg-lime      { background: var(--lavender); }
.ring-lime    { --tw-ring-color: var(--lavender); }
.border-lime  { border-color: var(--lavender); }
.bg-lime-soft { background: var(--lavender-dim); }

// Hero.tsx, AllRoundsTable.tsx, page.tsx
<span className="bg-lime">  // renders lavender 🤔

New devs grep "lime", find nothing relevant. Or see .bg-lime in JSX and expect green.

After · accurate names
// Use semantic Tailwind utilities
<span className="bg-lavender">
<span className="ring-mint">
<span className="border-mint">

// Or inline with CSS vars
style={{ background: "var(--lavender)" }}

Removes legacy alias entirely. Sweep is mechanical — ~10 minutes.

10

Spacing chosen ad-hoc

Within a single component you'll see gap-2, gap-2.5, gap-3, gap-4. Cards mix p-4 / p-5 / p-6 / p-7 for visually identical surface roles.

Before · 4 step values for similar roles

p-4 (16px)

Used in profile-row alert.

p-5 (20px)

Used in pool-row card.

p-6 (24px)

Used in admin section.

p-7 (28px)

Used in CreatePoolModal.

Decision rule: vibes.

After · 3-tier rule by surface role

Tight · p-3 (12px)

List rows, dense tiles.

Default · p-5 (20px)

Cards, profile blocks, pool rows.

Hero · p-7 (28px)

Modal panels, top-of-page heroes.

3 tiers. Documented as a design token.
