Mark system
Each mark is constructed on the same 200×200 grid using only circles, lines, arcs, triangles. The faint dashed construction guides are intentionally visible — they reveal the geometry rather than hide it, the way a Bauhaus or Wim Crouwel mark would. No faces, no eyes, no expressions.

The progression follows mathematical complexity: rank i is a single spiral (1 form), rank ii a 4-fold radial cross, rank iii an 8-fold mandala, rank iv a vesica piscis (the original sacred-geometry "fish"), rank v a sine arc, rank vi a forward-pointing triangle, rank vii nested arcs, rank viii a full golden-ratio composition with Fibonacci spiral, gold leaf finish, and animated foil sheen.

The typography drops Space Grotesk for headings in favor of Cormorant Garamond Italic — a high-design serif used by art galleries and luxury publications. Body labels stay in Space Mono for the technical contrast.
